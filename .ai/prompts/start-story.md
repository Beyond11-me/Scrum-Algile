# Start a story

Paste this into your AI tool, fill in the two fields, and attach the story text if your tool cannot read Notion.

```text
Story ID: <for example US-3.3>
Story text: <paste the title, description and acceptance criteria from Notion>

Read AGENTS.md first, then the code this story touches. Do not edit anything yet.

Reply in the language I use, with:
1. The goal in one or two sentences.
2. Acceptance criteria as a checklist. Mark any you inferred as "inferred, needs PO".
3. Questions for the Product Owner. If the story cannot be built without the answers, stop here.
4. The files you expect to change, and any area listed under "Areas that need extra care".
5. A short step-by-step plan, including the branch name.
6. Test cases for the main flow and the error cases.
7. Anything outside this story that you will not touch.
8. Whether this should be split into smaller Pull Requests.

Then wait. Start coding only after I approve the plan.
Once approved, work on the agreed branch and keep to the plan. If the plan has to change, tell me before you continue.
```
